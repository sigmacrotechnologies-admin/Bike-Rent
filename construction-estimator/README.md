# Cornerstone — Construction Estimator

Interactive construction cost estimator for new homes, additions, remodels, commercial fit-outs, and outdoor structures.

## Run locally

```bash
cd construction-estimator
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Notes

Pricing is sample U.S. planning data—useful for early conversations, not a formal contractor bid.
